# 库街区签到（astrbot_plugin_kuro_sign）

AstrBot 插件：每天自动完成**库街区**（`api.kurobbs.com`）的游戏签到与社区任务。

接口与请求参数移植自 [Night-stars-1/Kuro-Sign](https://github.com/Night-stars-1/Kuro-Sign)（MIT），
改造为异步、多账号、带错误分类的 AstrBot 插件。定时任务与存储结构参考
[Siq5005/astrbot_plugin_arknights](https://github.com/Siq5005/astrbot_plugin_arknights)（罗德岛终端）。

支持游戏：**战双帕弥什**（gameId=2）、**鸣潮**（gameId=3）。

## 功能

- **每日自动签到**：到点给所有已绑定账号签游戏内签到，可指定时区，默认 `00:05`。
- **多账号**：支持两种用法——面板里填一个公共 Token，或让每个用户在私聊里各自绑定。
- **社区任务（可选）**：社区签到、浏览帖子、点赞、分享，默认关闭。
- **结果推送**：群发送 `kj订阅` 后结果进群；没有群订阅时私聊给账号主人；
  Token 失效会额外私聊提醒（否则用户会一直以为签到正常）。
- **稳健**：退避重试、风控识别、单账号失败不影响其它账号、并发运行自动跳过。

## 安装

1. 把 `astrbot_plugin_kuro_sign` 整个目录放进 AstrBot 的 `data/plugins/`。
2. 面板里启用插件；依赖 `httpx`、`apscheduler`（AstrBot 本体已带，`requirements.txt` 也会声明）。
3. 打开插件配置，按需填写「基础设置 / 签到设置 / 社区任务 / 通知设置」四组配置。

## 绑定账号（三种方式）

### 方式一：短信验证码登录（不用抓包）

私聊机器人：

```
kj登录 13800138000          # 机器人尝试代发验证码
kj登录 123456               # 收到短信后回复验证码，5 分钟内有效
```

也可以一次发全：`kj登录 13800138000 123456`。

验证码收不到时，去库街区网页/APP 登录页（`kurobbs.com/login-page`）自己点「发送验证码」，
再把号码和验证码一起发过来即可——插件会自动降级到这条路径。

⚠️ **库街区是单设备登录**：登录成功后很可能把手机 APP 上的登录态顶掉，
需要在 APP 里重新登录一次。介意的话请用方式二。

### 方式二：网页版取 Token（**不用手机、不用抓包，最省事**）

在**电脑浏览器**上就能拿，两种方法任选：

**A. Network 面板（推荐，不用记 key 名）**

1. 浏览器打开库街区（如 `https://www.kurobbs.com/mc/home`）并登录；
2. `F12` → **网络 / Network** → 勾 **Fetch/XHR** → `F5` 刷新；
3. 点任意一个 `api.kurobbs.com` 的请求 → **标头 / Headers** → 请求头里找 `token` → 复制。

**B. Local Storage**

`F12` → **应用 / Application** → 左侧 **本地存储 / Local Storage** → 展开库街区域名 →
找 `auth_token`（wiki 子站上也可能叫 `WIKI_USER_TOKEN`），复制它的 Value。
（已确认前端登录成功后确实会 `localStorage.setItem(..., token)` 写入。）

然后私聊：

```
kj绑定 <Token> h5          ← 网页版取的，来源填 h5
kj绑定 <Token> android     ← 手机 APP 抓包的，来源填 android
```

⚠️ **两个来源不通用**：网页版填 `h5`、APP 抓包填 `android`，填错会校验失败
（插件失败时会提示你换一个来源再试）。

网页版属于 h5 端，**通常不会顶掉手机 APP 的登录态**；Token 有效期约两个月，过期重绑一次。

### 方式三：抓包拿 Token（手机与机器人共存）

1. 用抓包工具（Charles / Fiddler / HttpCanary）抓库街区 APP 的请求，
   在任意 `api.kurobbs.com` 请求的 header 里取 `token` 字段；
2. 或者直接用 [GetKjqToken](https://github.com/Night-stars-1/GetKjqToken) 获取；
3. 也可以在本机的**安卓模拟器**（雷电 / MuMu）里装库街区 APP，用 PC 上的抓包工具抓
   —— 全程不用真手机。

然后私聊 `kj绑定 <Token> android`。**不会顶掉手机 APP 的登录态**。

两种方式都在**私聊**里做：Token 和验证码都是账号凭据，插件不会把它们写进日志。

### 为什么没有「扫码绑定」

森空岛（明日方舟）有官方的扫码登录接口，所以罗德岛终端可以做成扫码；**库街区没有对外的
扫码登录接口**，本插件实测确认过：

- `api.kurobbs.com` 网关对未注册路径会统一返回 `code=220 访问令牌不能为空`，
  用「有 JSON 响应」判断路径是否存在会产生大量假阳性（已用对照路径验证）；
- 唯一确认可用的登录态接口是 `POST /user/sdkLogin`（手机号 + 短信验证码）与
  `/user/getSmsCode`，**没有**任何二维码生成 / 轮询接口；
- 库街区网页版登录页加载了极验（Geetest）风控脚本，短信登录也不是「无感」的；
- 社区里那种「在线登录」链接（如 `kuro.amoe.cc`）是**第三方中转服务器**：
  你的库街区 Token 会经过别人的机器。本插件不接这种方案。

所以「扫码」替不掉，只能退到短信验证码——它已经是官方接口里最接近扫码的免抓包方案。

## 配置项

| 分组 | 键 | 默认 | 说明 |
| --- | --- | --- | --- |
| 基础设置 | `sign_time` | `00:05` | 每日签到时间，`HH:MM` |
| 基础设置 | `timezone` | `Asia/Shanghai` | 定时任务时区。容器时区常是 UTC，显式指定可避免整体偏移 8 小时 |
| 基础设置 | `max_users` | `10` | 最多处理账号数，`0` 不限制 |
| 基础设置 | `request_timeout` | `15` | 单次请求超时（秒） |
| 基础设置 | `delay_seconds` | `3` | 账号之间的间隔（秒） |
| 签到设置 | `default_token` | 空 | 公共 Token，填了就每天签这个账号 |
| 签到设置 | `default_source` | `android` | Token 来源，`android` / `h5` |
| 签到设置 | `sign_game` | `两个都签` | **下拉选择**：两个都签 / 只签战双帕弥什 / 只签鸣潮 |
| 签到设置 | `enable_sms_login` | 开 | 允许用户用 `kj登录` 短信验证码登录；关掉后只能 `kj绑定` |
| 签到设置 | `auto_send_code` | 开 | 登录时代用户发验证码。库街区有极验风控，被拒时会自动提示用户自己去登录页点发送 |
| 社区任务 | `enable_bbs_tasks` | 关 | 社区任务总开关 |
| 社区任务 | `bbs_sign` / `look_post` / `like_post` / `share_post` | 开 | 各子任务开关 |
| 通知设置 | `notify_umo` | 空 | 额外推送目标，如 `astrbot:GroupMessage:123456` |

## 命令

| 命令 | 说明 |
| --- | --- |
| `kj登录 <手机号> [验证码]` | 短信验证码登录，不用抓包。分步：先发号码，再发 `kj登录 <验证码>` |
| `kj绑定 <Token> [h5\|android]` | 网页版取的填 `h5`，APP 抓包的填 `android`；私聊专用，群里发会被拒绝 |
| `kj状态` | 查看绑定、签到游戏、最近结果 |
| `kj签到` | 立即签自己的账号 |
| `kj游戏` | 弹出编号菜单：**接下来直接回 `1` / `2` / `3` 或游戏名就行**，不用再打命令（10 分钟内有效） |
| `kj游戏 <序号或游戏名>` | 一步到位，例如 `kj游戏 3`、`kj游戏 鸣潮`、`kj游戏 战双 + 鸣潮` |
| `kj任务 on\|off` | 开关社区任务 |
| `kj订阅` | 在群里开关本群的自动签到结果通知 |
| `kj解绑` | 删除本地保存的 Token |

绑定或登录成功后会自动弹出这个菜单，不用自己想起来打 `kj游戏`。

### 关于「按钮」

AstrBot 没有键盘 / 按钮类消息组件（QQ 侧也没有），所以做不到 Telegram 那种可点的
inline keyboard。这里的等效做法是：

- **WebUI 配置面板**：`默认签到游戏` 是真正的**下拉选择**；
- **聊天里**：弹菜单后**直接回一个序号**即可，交互上等同于点一下。

菜单等待只认一句话：回完就结束，回的是别的（或超过 10 分钟）就自动失效，
不会一直拦着你的消息。

## 与原脚本的差异

- `requests` 同步 → `httpx` 异步，不阻塞 AstrBot 事件循环；
- 社区任务的帖子列表改为取模索引，原脚本在帖子数少于任务次数时会 `IndexError`；
- 接口失败不再直接抛错打断整轮，只有 Token 失效才立即中断；
- 接口返回「今日已签到」按成功处理，避免每天重跑都报失败；
- 风控返回的是 HTTP 200 的非 JSON 内容，这里识别为可重试错误并退避重试；
- 签到游戏支持「序号 / 选项文案 / 游戏名 / 原始 ID」四种写法，不用记 gameId。
